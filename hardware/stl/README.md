# STL files

The printable parts for the Celebration Dispenser (a finger-wheel dispenser on
608 bearings). See [`../README.md`](../README.md) for the parts table, print
settings, bill of materials, and assembly.

| File                             | Role                                   |
|----------------------------------|----------------------------------------|
| `housing-main-608.stl`           | Main housing; holds the finger wheel + bearings |
| `housing-lid-608.stl`            | Housing lid                            |
| `vane-wheel-v5-half-blade.stl`   | Finger wheel — takes the zip-tie fingers      |
| `hopper-extension-onepiece.stl`  | Hopper body                            |
| `hopper-lid.stl`                 | Hopper lid                             |
| `stand-top-plate.stl`            | Plate the housing mounts to            |
| `stand-leg-single.stl`           | One stand leg — print ×4 (1 + mirror 3)|
| `stand-bottom-frame.stl`         | Base frame                             |

Preview renders of each part are in [`previews/`](previews/).
